      <div class="faq">


        <details>

          <summary>
            What is digital accessibility?
          </summary>

          <p>
            Digital accessibility means designing websites and digital
            products so that people with different abilities can use
            them effectively.
          </p>

        </details>



        <details>

          <summary>
            Who benefits from accessible websites?
          </summary>

          <p>
            Accessibility benefits people with visual, hearing, motor,
            cognitive, and other accessibility needs. It can also make
            websites easier for everyone to use.
          </p>

        </details>



        <details>

          <summary>
            Why isn't accessibility just an extra feature?
          </summary>

          <p>
            A website can look great and still be difficult to use.
            Accessibility should be considered from the beginning of
            the design process rather than added as an afterthought.
          </p>

        </details>



        <details>

          <summary>
            Can AI make websites more accessible?
          </summary>

          <p>
            AI can help explain content, summarize information, describe
            relevant visual content, and provide alternative ways to
            understand a page. It should support accessibility, not
            replace accessible design.
          </p>

        </details>



        <details>

          <summary>
            What can developers do to improve accessibility?
          </summary>

          <p>
            Developers can provide keyboard navigation, readable text,
            sufficient contrast, captions, alternative text, clear forms,
            predictable navigation, and accessible interactions.
          </p>

        </details>



        <details>

          <summary>
            Why should I experience the barriers myself?
          </summary>

          <p>
            Experiencing a simulated barrier can make an accessibility
            problem easier to understand. The goal isn't to reproduce
            someone's lived experience, but to demonstrate how design
            choices can create barriers.
          </p>

        </details>

<script>

  const menuButton = document.getElementById("menuButton");

  const navigationMenu =
    document.getElementById("navigationMenu");


  menuButton.addEventListener("click", function () {

    const isOpen =
      navigationMenu.classList.toggle("open");


    menuButton.setAttribute(
      "aria-expanded",
      isOpen
    );


    menuButton.setAttribute(
      "aria-label",
      isOpen
        ? "Close navigation menu"
        : "Open navigation menu"
    );

  });


  /* Close menu when a link is selected */

  const menuLinks =
    navigationMenu.querySelectorAll("a");


  menuLinks.forEach(function (link) {

    link.addEventListener("click", function () {

      navigationMenu.classList.remove("open");

      menuButton.setAttribute(
        "aria-expanded",
        "false"
      );

      menuButton.setAttribute(
        "aria-label",
        "Open navigation menu"
      );

    });

  });

</script>
